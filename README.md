# SableOS Platform Manifest

Authoritative multi-repository source composition for SableOS.

This repository defines which exact upstream and Sable-owned revisions compose a SableOS build. Development manifests may track active development revisions; validated build and release manifests must pin exact revisions.

Current primary reference target: Google Pixel 7 (`panther`) on the GrapheneOS 2026081300 / Android 17 substrate.

Application source, device implementation code, and host build tooling belong in their dedicated repositories rather than this manifest repository.
